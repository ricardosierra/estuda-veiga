## Como ler as conversões

- Cada arquivo Markdown contém um cabeçalho para cada página do PDF e preserva as quebras de página.
- Quando uma página não tem texto selecionável, o Markdown informa isso e aponta implicitamente para a página preservada no PDF.
- A conversão textual não reproduz necessariamente diagramas, imagens, fórmulas visuais, cores, disposição ou conteúdo que exista apenas como imagem. Use o PDF original quando esses elementos forem necessários.
- Os PDFs novos foram baixados pela interface Playwright do navegador autenticado via Portal/SSO em 14 de outubro de 2026 e convertidos com pdftotext em modo layout UTF-8.
- As contagens de páginas dos 8 PDFs novos foram comparadas com pdfinfo. A página 2 do calendário está em branco; a página 102 do e-book ASI1 é uma contracapa sem texto selecionável. Ambas foram conferidas visualmente e sinalizadas no Markdown.
