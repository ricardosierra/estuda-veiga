# Textos extraídos dos PDFs UVA — 2026.2

Este diretório guarda texto pesquisável, não cópias PDF. As fontes oficiais e o estado de cada tentativa estão no [inventário de materiais 2026.2](../../../MATERIAIS_2026.2.md).

## Bases de Programação

| Fonte | Texto no repositório | Fonte oficial |
|---|---|---|
| Capítulo 1 | [capitulo-01.txt](bases-de-programacao/capitulo-01.txt) | [PDF UVA](https://ead.uva.br/disciplinas/grad/publica/cont/abc/bpr/eb/BPR_Cap_01.pdf) |

O capítulo 1 foi obtido pela opção de download do Canvas e convertido com pdftotext -layout -enc UTF-8. As outras fontes PDF deste semestre não foram extraídas: o acesso direto respondeu HTTP 403.

## Limites

A extração preserva o texto selecionável, mas não reproduz necessariamente diagramas, imagens, disposição visual ou conteúdo que exista somente como imagem. Como os PDFs originais não são retidos, consulte os links oficiais quando esses elementos forem necessários.
