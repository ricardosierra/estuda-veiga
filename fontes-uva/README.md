# Fontes UVA

Textos extraídos de PDFs e documentos oficiais da UVA, separados por período e por matéria. O PDF original não é versionado: fica local e ignorado pelo Git. Cada texto guarda a página e o link oficial de origem.

- [2026.2](2026.2/README.md): Bases de Programação, Cálculo, Estatística, Linguagens Formais, Paradigmas e Projeto de Extensão.
- [2026.1](2026.1/README.md): textos de unidades, apoio e documentos institucionais.
- [Relatório de extração de 2026.1](2026.1/extraction-report.json)

Para não duplicar um texto, a pasta de matéria em `materias/` deve apontar para o arquivo daqui, e não copiá-lo.
