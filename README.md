## Git

Repositório Git local, na branch `main`, sem remoto configurado. Os documentos Markdown de planejamento, registro acadêmico, links oficiais, notas autorais e trabalhos convertidos são mantidos em texto para versionamento. Os documentos-fonte completos ficam na pasta local `originais/`, ignorada pelo Git. PDFs, Word, Pages e demais binários são ignorados, com exceção dos três diagramas UML pequenos referenciados pelo trabalho de Paradigmas. Credenciais e identificadores pessoais não devem ser adicionados ao repositório.
