# Acervo acadêmico — Faculdade

Repositório local para organizar planejamento e arquivos acadêmicos em formatos de texto. Materiais binários baixados ficam na pasta `materiais/`, mas não entram no Git.

## Endereços

- [Portal do Aluno UVA](https://portalaluno.uva.br/Aluno/PortalAluno)
- [Canvas UVA](https://uva.instructure.com/)

As credenciais não são armazenadas neste repositório. Entre diretamente no portal.

## Arquivos principais

- [Planejamento e rotina para os próximos semestres](PLANEJAMENTO.md)
- [Disciplinas, unidades e links do Canvas de 2026.1](CURSOS_2026.1.md)
- [Inventário de materiais e downloads](MATERIAIS_2026.1.md)
- `materiais/2026.1/`: cópias locais dos materiais baixados. Os PDFs são ignorados pelo Git.

## Git

Repositório Git local, na branch `main`, sem remoto configurado. A documentação segura em texto (`.md`) está versionada. Arquivos de estudo em texto sem dados pessoais também podem ser versionados; dois `.txt` acadêmicos preexistentes com dados pessoais e os arquivos binários permanecem locais e ignorados pelo Git. Credenciais e identificadores pessoais não devem ser adicionados ao repositório.
